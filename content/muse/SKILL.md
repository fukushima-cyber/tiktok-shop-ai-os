# TikTok Shop 制作運用ガイド（エージェント設定リファレンス）

ユーザーがローカル環境やカスタムスキルとしてこの制作フローを運用する際の推奨設定、最新仕様の参照方針、品質基準をまとめています。

---

## 1. 最新仕様の参照方針（ローカル設定と制作基準の分離）

- **ローカル設定（環境固有の情報）**：共有Drive設定、ナレ音声（Nanami）、1.2倍速、-14 LUFS、日本語フォントパスなど環境設定のみローカルに保持します。
- **制作基準・各工程マニュアル（常に公開版の最新を参照）**：新しい商材の企画・台本制作を始める際は、ローカルの古い要約だけに頼らず、`https://fukushima-cyber.github.io/tiktok-shop-ai-os/llms.txt` および実行する工程ページ（`skills/01〜07.md`）の最新版を確認して進めます。これにより、依頼者が商材名だけを伝えても最新の品質基準で一貫して制作できます。

---

## 2. 全工程で外さない制作基準（コア要約）

1. **工程01（リサーチ＋実素材インベントリ）**：公式情報・NG境界・競合動画の勝ち型/飽和型・買わない理由5選に加え、共有Drive「TTSオートフロー」の `素材一覧_全商品.md` と対象商材フォルダの実映像を確認し、`brief/research_brief.md` と `brief/asset_inventory.md` に整理してから工程02へ進みます。
2. **工程02（素材適性フィルター＋フォーマット分離＋ベネフィット必須）**：発散前に `asset_inventory.md` の物理制約で成立しない型を除外し、**通常尺（20秒〜）は生活ベネフィット最低2場面、超短尺速報（10〜15秒）・無言シズル型でも核心ベネフィット最低1点** を設計します。複数案を作るときは特徴の言い換えにせず、**フォーマット（尺・語り口・感情構造）とベネフィット軸の両方** を別物にします。トクトクSALE・ブラックフライデー期は家電・食品・日用品の実測勝ち型（まとめ買い／後悔逆転／速報価格確認）を輸入します。
3. **工程03〜06（映像実況禁止・4つの編集ルール・TTSカタコト防止・高精細バッジ）**：
   - 画面を見れば分かる動作説明を言葉でなぞる **映像の実況中継を行わず**、画＝視覚の証拠、言葉＝買い手の本音とベネフィットに分担します（固定25秒上限なし）。
   - テロップは **画面ど真ん中（`telop_y="center"`）固定・句読点（、。）なし・句読点を打つ自然な区切り位置で `\n` 改行（単純1行10文字以内・最大2行）・`{{yellow:...}}` / `{{pink:...}}` の部分色強調** を徹底し、締めの左下白矢印は TikTok Shop 商品リンク直上（`x=80〜380, y=1130〜1410`）へラスト2カット（約4〜6秒）連続配置します。セールバッジ（`--kind badge --subtext sale|bf`）や注記付きレビュー傾向カード（`--kind review --footer`）は `broll_hunter.py` の2倍解像度版を使用し、TikTokアプリ内で声・BGMを後入れする運用にも対応する **`*_silent_for_tiktok.mp4` 無音マスター** を標準出力します。
   - **Neural TTS（Nanami等）へはスペースなしの自然な漢字かな混じり文** を渡し、誤読語（`今トクトク→いまトクトク`、`SALE→セール` 等）だけピンポイント置換してカタコトを防ぎ、`render_video.py --verify-whisper` で全カット照合します。`（対象のときだけ）` のような仮カッコ書きやト書きを本文に残しません。

## 3. 推奨する初期設定（ユーザーの依頼に応じて構成）

1. **作業フォルダ構成（任意の作業ディレクトリ配下）**：
   - `brief/`（`research_brief.md`・`asset_inventory.md`）、`assets/`（素材一時保存）、`sfx/`（効果音）、`work/`（中間ファイル・0.5秒フレームシート）、`output/`（完成mp4・コンタクトシート）、`ledger/`（アカウント実績・ローカル型記録・`exemplars.md` Good/Bad対照ペア）
2. **環境確認（`scripts/preflight_muse.sh`）**：
   - `ffmpeg` / `ffprobe` / `python3` / `pillow` / `edge-tts` / 日本語ゴシックフォントの有無を事前に確認します。
   - 日本語フォントが未導入の環境ではテロップが文字化けするため、利用可能な日本語ゴシックフォントのパスを控えておきます。
3. **共有Google Driveと素材管理**：
   - デフォルトの共有素材置き場は Google Drive「TTSオートフロー」（`https://drive.google.com/drive/folders/1OPd1eGR5EpWh3-QVqDrG1W86MjlGoMuW`）です。
   - まず `素材一覧_全商品.md`（`https://drive.google.com/uc?export=download&id=1ypjOJlJQbRdsYdpx1JzLuTinDahbXFbI`）とDrive内の対象商材フォルダを確認します。
   - 共有フォルダ内のファイル移動・削除・共有設定変更は、依頼者の明示的な承認なしに行いません。
   - Google Drive Connector が連携されている環境では、大容量動画の読み書きや完成mp4の共有にコネクタを使うと安定します。
4. **効果音の扱い**：
   - 効果音ラボの標準7種（`core/00-os-principles.md` 参照）を使用する場合は、ローカル作業フォルダの `sfx/` に保存して再利用します（再配布は不可）。外部サイトから直接取得できない環境では、依頼者にGoogle Driveの `sfx` フォルダへ配置してもらいます。

## 4. 運用上の注意点と代替手段

### ベース映像の素材ポリシー
- **ベース映像は実写のみ**：AI動画生成、AI画像生成のスライド動画化、単色背景や仮画面での実写カット代用は行いません。
- **編集エフェクト・GIFオーバーレイは可**：実写ベース映像の上に乗せる左下白矢印の動くGIF、コメント吹き出し、控えめな強調演出の作成・合成は可能です（赤矢印連打・白フラッシュ・色加工・左右反転は不可）。
- **実写素材が不足する場合**：①共有Google Drive内の別実写カット・別区間 → ②公開実写フリー素材（Pexels / Mixkit）→ ③編集を止めて依頼者へ不足カットの追加を相談します。

### 外部サイト・ツール制限時の代替手順

| 状況 | 避けること | 推奨する代替手順 |
|---|---|---|
| **外部動画サイトが開けない・取得制限がある** | 認証情報の不正利用やアクセス制限の回避、AI映像での代用 | Google Drive内素材または実写フリー素材（Pexels / Mixkit）を使い、不足分は依頼者へ共有を依頼する。 |
| **公開データからアカウント数値が取得できない** | 再生数やいいね数を推測で記入する | 依頼者へTikTokインサイトやTikTok Shop管理画面のスクリーンショット共有を依頼し、画像から読み取って記録する。 |
| **指定の音声合成ツールが使えない** | 無音のまま納品する、別言語の音声へ勝手に切り替える | 状況をそのまま報告し、代替音声またはナレーション提供を相談する。 |
| **完成動画の容量が大きくチャット送信できない** | ローカルに置いたまま終了する | Google Drive等の共有先へ保存し、確認用リンクとコンタクトシート画像を添えて渡す。 |
| **ffmpegのコマンド引数で日本語や記号エラーが出る** | 長大なワンライナーを手組みする | `scripts/render_video.py` に `plan.json` を渡して実行する（Pillow透過PNG合成により `drawtext` 不在環境や記号でも安定動作）。 |
