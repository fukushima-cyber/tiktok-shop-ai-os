# Skill 07：投稿パッケージ & 48h振り返りPDCA

> **使うタイミング**：①ゲートCで動画が承認された直後（投稿準備）、②投稿から48時間後の数値振り返り時。
> **読むファイル**：`./core/00-os-principles.md`（第3章：3段階評価軸）＋ 変数A（アカウント）＋ 変数B（案件）。
> **ゴール**：動画を作って終わりにせず、「投稿設計→48h計測→ボトルネック特定→次回1本のブリーフ生成」まで運用ループを閉じる。

---

## モードA：投稿パッケージ生成（ゲートC承認後）

完成動画と一緒に、投稿に必要なテキスト・運用設計・実績登録レコードを1セットで出力します（投稿実行は必ず依頼者承認後）。

### 出力する5点セット
1. **キャプション案（2パターン）**
   - 1行目は動画の結論をネタバレさせすぎず、コメントやクリックを促す短い一文。
   - 末尾に `#PR`（ステマ規制対応）と、案件ルールで許可された文言のみ記載（NG語・未確認の終了日・価格は入れない）。
   - TikTok Shop誘導（例：「左下のショップから詳細見れます」）。
2. **ハッシュタグ（4〜6個）**
   - 商品名（1〜2個）＋ 悩み・ジャンル系（2〜3個）＋ `#TikTokショップ` / `#PR`。
3. **サムネイル用フレーム提案**
   - 動画内で一番「何の話か一目で伝わる」秒数とテロップ位置を指定。
4. **投稿直後の固定コメント／想定質問への返信テンプレ**
   - 例：「香りどれくらい持つ？」「敏感肌でも使える？」など、よくある購入前の不安に対する誠実な返信案（薬機法・事実ベース）。
5. **投稿実績DB 登録用レコード（投稿前記入分）**
   - 投稿名 / 商材 / アカウント / 配信区分（有機 or 広告。未定なら「依頼者に確認」） / 使った型（`Pxx × Sxx`） / 仮説（1つ） / 変えた項目（1つ） / 48時間計測予定日時（JST）。

---

## モードB：48時間後の振り返り & 次回ブリーフ自動生成

投稿から48時間後（JST）の数値を受け取ったら、以下のルールで機械的に診断し、次の1本の指示書を生成します。

### 入力してもらう数値
- 配信区分（有機／広告 ※混ぜない）
- 再生数 / いいね数 / 保存数 / シェア数 / コメント数 / カートクリック数（分かれば） / 注文数（CV）
- 今回の型（`Pxx × Sxx`）・仮説・変えた項目

### 3段階ボトルネック判定マトリクス

| 判定パターン | 数値の条件（有機48h基準） | 診断 | 次の一手（次回ブリーフの方針） |
|---|---|---|---|
| **① 勝ち型（横展開）** | 再生 ≥ 1,000 **かつ**（いいね率 ≥ 0.5% **または** 保存率 ≥ 0.15% **または** 注文発生） | 構造が当たっている | **同型で1変数だけ変えて横展開**（例：冒頭のシチュエーション違い、別ベネフィット）＋ Spark Ads出稿候補として提案。 |
| **② フック不足** | 再生 < 1,000 **かつ** いいね率 ≥ 0.5%（または保存率 ≥ 0.15%） | 中身は良いが冒頭で止まっていない | **型・中盤・商品パートは完全固定**。冒頭0〜2秒（画＋テロップ）だけ差し替えて再検証。 |
| **③ 中盤・訴求不足** | 再生 ≥ 1,000 **かつ** いいね率 < 0.5% かつ 保存率 < 0.15% かつ 注文 0 | 冒頭は止まったが中身で離脱／刺さらない | **冒頭0〜2秒は固定**。中盤のテンポ（1.5秒カット）・絵と主語の一致・認識転換の説得力を改修。 |
| **④ CV導線不足** | 再生 ≥ 1,000 かつ いいね/保存は高いが、クリック・注文 0 | 共感止まりで「今買う理由」が弱い | **冒頭・中盤は固定**。商品パートの情景化・理由の4段重ね・左下CTA・固定コメントを改修。 |
| **⑤ 全面未達（撤退）** | 再生 < 1,000 かつ いいね率 < 0.5% かつ 保存率 < 0.15% かつ 注文 0 | この型×商材が噛み合っていない | **この型は撤退（二度と出さない）**。Skill 02へ戻り、別系統の型で新規企画。 |

※ 広告配信（Spark Ads）の結果が来た場合は、有機の合格判定には使わず **「CPA / 注文数 / 保存率」** ベースで別枠評価します。
