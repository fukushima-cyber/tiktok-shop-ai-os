# Skill 06：自動動画編集 & 機械検査（ゲートC）

> **使うタイミング**：ゲートBで台本・ビートシートが承認された直後。
> **読むファイル**：変数A（声・倍速・音量目標・効果音割り当て・テロップ見た目・顔出し可否・生成素材・締めの誘導）＋ 変数B（素材一覧・香りの見分け・禁止順）＋ `./scripts/edit_pipeline_ref.sh`。
> **ゴール**：効果音入りの本線mp4＋効果音なし（ナレのみ）mp4の2本と、コンタクトシート・機械検査ログを揃え、依頼者のゲートCへ渡す。

---

## 1. 実行手順（必ずこの順で進める）

### Step 1：音声生成（TTS）＋ 文字起こし照合
1. 台本の「読み（ひらがな）」原稿を使う（行中の「。」は「、」に置換済み。テロップは漢字のまま）。
2. 変数Aの `{ナレの声}`（例：Microsoft `ja-JP-NanamiNeural` / `edge-tts`）で **標準速（1.0倍）** の音声を作る。
   - **厳禁**：生成時に+20%などで速くしない（仕上げの全体倍速と二重になるため）。
   - 指定の声を出せない環境なら、別の声で代用せず止まって依頼者に聞く。
3. 前後の無音をカットし、行中に0.3秒以上の無音が残る場合だけ詰める。
4. 音声の合計尺 ÷ `{全体の倍速}` を計算し、**完成尺が15〜25秒に収まるか実測確認** する。25秒を超える場合は、編集に入らず台本（Skill 04）へ戻して行を削る。
5. 書き出した音声全体を Whisper 等で文字起こしし、台本と全行照合する。誤読・抜けがあれば音声を作り直す。

### Step 2：素材の事前フレーム確認（ファイル名だけで選ばない）
使う全素材について、頭・中・終わりの静止画を切り出して目視（またはビジョン検査）で確認する。
- 顔出し可否が変数Aどおりか（顔出し不可の場合、ぼかし・モザイクも不可。画角の端の一瞬もNG）。
- 他社ロゴ・REDの透かし・中国語字幕・元字幕が、**2倍以内の寄せ（クロップ）** で完全に画面外へ出せるか。出せない素材は不採用。
- 案件固有の識別ルール（例：センスウェア `08` はベルガモット、`09` は左ホワイトムスク／右ベルガモット、`12a` は箱の文字を確認）。
- 手元が映るカット同士（肌色・太さ・袖・時計）が別人にみえないか。ズレる生活カットは「手が映らない絵（足元・後ろ姿・物）」に替える。
- 止まって見える素材・止め絵は使わない。

### Step 3：色空間統一・カット編集・テロップ配置
- **出力規格**：縦9:16（`1080×1920` / `30fps`）、全カット画面いっぱい（ぼかし帯・枠なし）。
- **色加工・左右反転は一切禁止**：彩度・LUT・ノイズ処理・左右反転をしない。
- **HDR（HLG）とSDRの混在処理**：HLGの自社素材とSDR（BT.709）のRED/フリー素材をつなぐ場合のみ、色補正ではなく色域・伝達関数変換のみ行う（式は `./scripts/edit_pipeline_ref.sh` 参照）。変換後、白い画面の信号が約75%（BT.2408基準白）であることを確認する。テロップの白も8bit RGB 191（約75%）に合わせる。
- **寄せ倍率の上限**：元画角に対して **2.0倍以内**（縦720×1280→1080×1920の単純拡大は1倍。横1920×1080→縦切り出しは約1.78倍として合算する）。
- **尺不足の引き伸ばし**：1カット **1.1倍スロー（`setpts=1.1*PTS`）まで**。口元・手が動くカットには使わない。かけたカットと倍率はnotesに明記する。
- **同一素材ファイルの使用**：原則1本につき1回。足りない場合のみ重ならない別区間を使い、notesに明記する。
- **カット間**：無音の隙間・待ち時間・静止フレームをゼロにする（旧編集ルールDBの「後ろ+0.2秒」は不採用）。
- **公式商品画像**：動画内 **1か所まで**。
- **テロップ**：
  - 読み上げと **一字一句一致（漢字のまま）**、その行が読まれている間だけ **フレーム番号指定** で出し入れする（1フレーム残存を防ぐ）。
  - 位置：有機投稿は中央ぞろえ `x=180〜900`・`y<1500`。広告配信予定ならTikTok公式安全領域（上240px・下660px・左右120px空き、`y>840` は右端 `x<=780`）に収める。
  - 顔・背中・動きの中心・商品の顔になる部分・締めの誘導には絶対に重ねない。収まりに字を小さくせず改行する。

### Step 4：効果音ミックス・全体倍速・2本書き出し
1. 効果音は変数Aの `{効果音の割り当て}` に従い、効果音ラボ等の実音を使う（合成音禁止）。
2. **要点だけ4〜6か所**（1行1回まで、同音連続禁止、通常のテロップ切替には鳴らさない）。余韻は自然に消えるよう短く整える。
3. 置き位置は原則その行の頭フレーム。ナレ頭と重なってピークが `-1dBFS` を超えるときだけ2〜3フレーム前へずらす。
4. 32bit浮動小数で線形ゲイン合わせ（強い自動 `loudnorm` でナレを潰さない）。効果音ピークはナレのピークより **3〜6dB低く** する。
5. 全体目標は `{音量目標}`（例：`-14 LUFS` ±1 LU）、**ピーク `-1dBFS` 以下・クリップ（割れ）サンプル数 0**。
6. 仕上げに **映像と音声をまとめて `{全体の倍速}`**（例：1.2倍）にする。
7. **効果音入りの本線mp4** と **効果音なし（ナレのみ）mp4** の2本を書き出す（完全無音版は作らない）。

## 2. ゲートC前の機械検査チェックリスト（実測値で埋める）

推測でチェックを付けず、すべてフレーム画像とffprobe/ffmpeg計測値で確認してから提出します。

- [ ] 解像度 `1080×1920` / `30fps` / 全カット画面いっぱい
- [ ] 完成尺（倍速後）が **15〜25秒**（実測：____秒）
- [ ] 全カットの頭・中・終わりコンタクトシートで、顔・他社ロゴ・元字幕・静止感なしを確認
- [ ] 寄せ倍率 ≤ 2.0倍／左右反転なし／色加工なし（HLG基準白約75%一致）
- [ ] 音声文字起こし結果が台本と全行一致
- [ ] テロップが人物・商品・UI・締めの誘導と重なっていない
- [ ] 効果音4〜6か所・割り当て固定・ナレより3〜6dB低い・全音聞き取れる
- [ ] 音量 `-14 LUFS` 付近／ピーク `≤ -1dBFS`／割れサンプル 0
- [ ] 商品パートが動きっぱなし・白フラッシュなし・赤い矢印なし
- [ ] 本線mp4・ナレのみmp4・コンタクトシート・検査notesの4点が揃っている
- [ ] 投稿・送信・公開はしていない

---

## 3. 差し戻し（直し）時のルール

- 依頼者から修正指示が来たときは、**指示された箇所だけ直す**。
- 指示にない箇所、特に冒頭0〜3秒は確認なしに勝手に差し替えない。
