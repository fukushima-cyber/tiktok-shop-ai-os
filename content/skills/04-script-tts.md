# Skill 04：TikTok口語台本 & 読み上げ・改行最適化

> **使うタイミング**：Skill 03 の連続音読稿ドラフト＆ビートシートが確定した直後。
> **必須で読むファイル**：共通ガイド（`./core/00-os-principles.md`）＋ `brief/research_brief.md`（NG表現・特典の正式表記・読み指定）＋ `brief/asset_inventory.md`（手元キャラ・顔出し制約）。
> **ゴール**：**「映像の実況中継」「機能押し」「ぶつ切り単語メモ」「仮カッコ残存」を完全に排除**し、生活ベネフィットが2場面以上刺さる自然な口語台本と、文節で綺麗に揃った `\n` 改行・TTS用ひらがな原稿を仕上げる。

---

## 1. 最重要：映像の実況中継を禁止し、生活ベネフィットで1本の会話に仕上げる

Skill 03 で書いた連続音読稿ドラフトをベースに、必ず次の3ステップで最終台本へ磨き上げます。**いきなりカット表の1行ごとに「その画の説明」を書き込んではいけません。**

### Step 1：連続音読稿（130〜180字）の仕上げ＆「映像実況」の完全削除
1本の連続した話し言葉として声に出して読み、次をすべて潰します。

1. **映像の実況中継を消す（最大3カット未満に抑える／原則ゼロ）**
   - 画面を見れば1秒で分かる動作（「自分で開けてみる」「キャップを外して」「スポイトから落ちる、このとろみ」「頬に1滴」「長い爪のままで伸ばせる」「塗った直後のこのツヤ」）を言葉でなぞらない。
   - **役割分担**：画面＝とろみ・伸び・ツヤ・スポイト・ラベルを見せる「証拠」。言葉＝「だから朝メイク前／寝る前／外出先でどう楽になるか」という「買い手の本音と生活ベネフィット」。
2. **「機能・質感・開封」をすべてベネフィットへ翻訳する（フォーマット別基準）**
   - 機能・成分・質感の説明は全体の **3割以内** に抑える。
   - **通常尺（20秒〜）は具体的な生活ベネフィット最低2場面**、**超短尺速報（10〜15秒）や無言シズル先行型でも核心ベネフィット最低1点** を必ず入れる（ベネフィット0は全型で不合格）。
   - **語り手の温度感を「丁寧な通販解説調」1択に丸めない**：速報ニュース調、低評価へのツッコミ調、無言シズル＋最小字幕、失敗談からの本音日記調など、選んだフォーマットのキャラとリズムを最後まで貫く（事実の誇張や薬機法違反は禁止しつつ、ありふれた悩み・本音の語り口は活かす）。
3. **未確認の仮カッコ書きを本文に1文字も残さない**
   - ❌ `今トクトクSALE中（対象のときだけ）` / `〇〇円（要確認）`
   - 未確認のセール・特典・価格は本文に入れず、末尾の「未確認事項」欄に追い出し、本文は確定事実だけで成立させる。

## 2. 実例で学ぶ：最悪のNG台本（映像実況・ベネフィット0）→ 正解の書き換え

以下は同じ手持ち素材・同じ薬機法制約（効能断定なし・顔出しなし）での比較です。**左のような台本は1本も出してはいけません。**

### ❌ 最悪のNG例（映像の実況中継＋ベネフィット0＋仮カッコ残存）
> 「流れすぎて、怪しい。怪しいから、自分で開けてみる。まず中身。キャップを外して。スポイトから落ちる、このとろみ。いきなり顔で試す。頬にそのまま1滴。長い爪のままで、のばせる。塗った直後の頬、このツヤ。CICA3種とPDRN。KINUIのカームセブン。疑ってごめん、これは好き。宣伝かより、中身で決めて。今トクトクSALE中（対象のときだけ）。気になってた人は、左下から」

**なぜ即不合格か（5つの致命傷）**：
1. **14カット中8カットが映像の実況中継**（開ける→キャップ外す→とろみ→頬に1滴→長い爪で伸ばす→ツヤ）で、画面と文字が重複している。
2. **生活ベネフィットが0個**。視聴者からすると「で、なぜ急に『疑ってごめん、これは好き』になったの？私のどの悩みが楽になるの？」が全く分からない。
3. **0.0秒が「棚に緑の箱だけ」の静止カット**で動きも事件もない。
4. 顔出し不可・手元素材前提なのに「頬に1滴」と制約違反を起こし、さらに「長い爪のままで伸ばせる」という視聴者に無関係な手元描写を無理やり実況している。
5. `（対象のときだけ）` という未確認メモがナレーション本文に残っている。

### ✅ 正解の書き換え例（同じ手持ち素材・画と文字の役割分担・生活ベネフィット2場面）
**連続音読稿（約168字・1.2倍速で約20秒）**：
> 「朝のメイク前に、ベタつく美容液って本当に無理じゃない？ 私もそれがいやでずっと避けてたんだけど、これに変えてから朝の支度がマジで楽になった。とろみがあるのに、伸ばした瞬間にすっとなじむから、乾くのを待たずにそのままファンデにいけるの。寝る前に塗ってもすぐスマホ触れるくらい軽いし、乾燥でゆらぎやすい日でもCICAとかの整肌成分が7種類入ってるから頼りやすい。KINUIのカームセブン、ベタつきが苦手な人だけ左下から見てみて。」

**なぜ強いか**：
- **0.0秒から最強の動きカット（手の甲に1滴→伸ばす）** を先出しし、言葉は「朝のメイク前にベタつく美容液無理じゃない？」と日常のイライラを直撃。
- 映像で「とろみ・伸び・ツヤ・スポイト・ラベル・箱」を証拠として見せながら、言葉は **生活ベネフィット①（乾くのを待たずそのまま朝メイクにいける）** と **生活ベネフィット②（寝る前に塗ってすぐスマホ触れるくらい軽い）** を語っている。
- 薬機法違反（治る・消える等）ゼロ、映像実況ゼロ、仮カッコ書きゼロ、手元のみ（顔出し不可）と100%一致。

## 3. その他のダメ表現パターン（連続音読テストで必ず潰す）

| やりがちなダメ例 | なぜダメか | 直し方（✅ Good） |
|---|---|---|
| ❌「鏡じゃない、人に言われた」 | 鏡は喋らない。AI特有の無理な対比構文（「Aじゃない、Bだ」）で意味が壊れる。 | ✅「友達に『最近肌疲れてない？』って言われて地味にショックだった。」（※対人素材がある場合のみ） |
| ❌「攻めるケア、足しすぎてた。見直したのは、成分。」 | ぶつ切りの体言止め連発で、因果が飛んでいる。 | ✅「いろいろ重ね塗りしすぎてたから、一回シンプルなケアに戻したくて選んだのがこれ。」 |
| ❌「3つのCICAに、PDRN、ナイアシンアミド、ティーツリー、パンテノールまで、7つ。」 | ラベル成分のただの朗読。視聴者は「で、何が嬉しいの？」が分からない。 | ✅「乾燥でゆらぎやすい日でも、CICAとかの整肌成分が7種類入ってるから頼りやすい。」 |
| ❌「顔に使う前に、この質感で選んでる」 | 顔素材がない言い訳を無理やり言葉にして日本語が破綻している。 | ✅「重たい美容液が苦手なんだけど、これは伸ばした瞬間にすっとなじんで朝メイク前でも待たなくていい。」 |
| ❌「気になったら、左下から見てみて」（理由ゼロ） | 誰に向くか・今押す理由が何もない。 | ✅「ベタつく美容液が苦手な人だけ、左下から見てみて。」（確定特典があるときだけ理由を2〜4段重ねる） |

### 機能→生活ベネフィット変換チェック表

| ❌ 機能押し（スペック・使用感止まり） | ✅ 生活ベネフィット（行動・時間・気分の変化） |
|---|---|
| 「7つの整肌成分が入ってる」「CICAやPDRN配合」 | 「あれこれ重ね塗りしなくて済むから、**夜のスキンケアが1分で終わって迷わなくなる**」 |
| 「とろっとして伸ばすとツヤが出る」「なじみがいい」 | 「乾くのを待たなくていいから、**朝バタバタでもすぐファンデを塗れる**／**寝る前にすぐスマホを触れる**」 |
| 「スポイト式で量を調整しやすい」 | 「出しすぎてベタつく失敗がないから、**忙しい朝でも雑にサッと塗れる**」 |
| 「練り香水だから音がしない・缶が小さい」 | 「席やトイレで**誰にも気づかれずにサッと塗り直せて**、夕方まで香りを気にせず過ごせる」 |
| 「マグネット吸着で強力」（ガジェット） | 「カバンの中でコードが絡むイライラが消えて、**取り出して1秒で充電できる**」 |

> **テスト基準**：台本から「成分・容器・質感・動作実況」の行を全部消したとき、**使う人の具体的な生活場面（朝・夜・通勤・仕事・外出など）と行動・気分の変化が2場面以上残らない台本は不合格**。

## 4. カット割り・テロップ改行（`\n`）・TTSの厳守ルール

連続音読稿が完成してから、Skill 03 のビートシートに合わせて 1.5〜2.2秒（12〜20文字）のまとまりでカットに分けます。

### テロップ表記・改行・配置の厳守ルール（下手な改行と読みにくさを構造的に防ぐ）
- **配置は原則「画面のど真ん中（上下左右中央：`telop_y="center"`）」に統一する**。
- **テロップに句読点（「、」「。」）は入れない**（読み上げ用 `reading` には自然な間のために「、」を入れてよい）。
- **改行位置は「句読点（、）を打つような自然な区切り位置」に必ず揃える**。
  - ❌ `1つ目、伸ばすと\nすっとなじむ` / `こってり保湿が\n好きなら物足りない`（文節の途中で切れており、句読点も残っている）
  - ✅ `1つ目\n伸ばすとすっとなじむ` / `こってり保湿派なら\nちょっと物足りない` / `安くなってる今のうち\n左下から見てみて`
- **1行は最大10文字（半角英数は2文字＝1文字換算）、1カット最大2行まで**。
- **必ず台本側で `\n` を明示する**（自動折り返し任せにしない）。
- **単語・商品名・カタカナ語・数字＋助数詞を絶対に途中で割らない**。
  - ❌ `これはKINUIのカーム\nセブン` / `ナイアシンアミド、テ\nィーツリー` / `パンテノールまで、7\nつ`
  - ✅ `KINUIの\nカームセブン` / `伸ばした瞬間に\nすっとなじむ` / `ベタつきが苦手な人だけ\n左下から見てみて`
- **2行目に1〜2文字だけ落とす「孤立文字」は厳禁**（❌ `人に言わ\nれた` / `足しすぎ\nてた`）。
- **上下の行の文字数バランスを揃える**（例：7文字＋7文字、6文字＋8文字）。

### 言語化とTTSの追加ルール
1. **禁止の抽象ワード**：`おすすめ` / `コスパ最強` / `画期的` / `すごい` / `最高` / `魅力的` / `必見` / `解決してくれる` だけで価値を語らず、生活場面と行動の変化で書く。
2. **特典の正式表記は1文字も変えない**：`brief/research_brief.md` で確定した正式文言のみ使用。対象可否・価格・終了日が未確認なら本文には入れない。
3. **締めの「今買う理由」を2〜4段重ねる**（確定事実の範囲で）：向く人の特定 → 使い道／失敗しにくさ → （確定していれば）特典・タイミング → 左下誘導。
4. **読み上げ（TTS）用原稿（カタコト防止ルール）**：
   - **Neural TTS（`ja-JP-NanamiNeural` 等）には「スペースなしの自然な漢字かな混じり文」を渡す**。全文をひらがなにしたり単語間にスペースを入れると、高低アクセントが崩れてカタコトになるため禁止。
   - **ひらがな・カタカナへ置換するのは「実際に誤読が起きる語だけ」ピンポイントに行う**（例：`SALE`→`セール`、`今トクトク`→`いまトクトク`、`KINUI`→`キヌユイ`、`CICA`→`シカ`、`PDRN`→`ピーディーアールエヌ`）。
   - 行中の「。」は読み原稿だけ「、」に替える（0.3秒以上の無音間延び防止）。テロップは句読点ゼロ。
   - TTS（標準速）を書き出して `{全体の倍速}` をかけた実測尺を確認する（固定の25秒上限は不要。無音の間延びや言い直しだけ削り、ベネフィットを削ってまで短くしない）。

## 5. 台本出力フォーマット

```markdown
# 台本：【企画タイトル】

## 連続音読稿（全130〜180字・映像実況ゼロ・生活ベネフィット2場面以上）
（ここにカット割り前の連続した全文を書く。声に出して意味・因果・ベネフィットに1ミリも違和感がない状態にする）

---

## カット割り台本（\n で改行位置を明示・1行10文字以内・最大2行）
- **ターゲット**：
- **企画**：
- **型**：`Gxx`（または `Pxx` / `Lxx`）× `Sxx`
- **生活ベネフィット①②**：①〇〇 ／ ②〇〇
- **未確認事項（本文には入れずここに記載）**：

| Cut | 目安秒(1.2x後) | テロップ（句読点なし・句読点位置で\n改行・1行10字以内） | 読み（TTS用・ひらがな） | 絵（素材ID・画の内容） | テロップ位置 | 効果音 |
|---|---|---|---|---|---|---|
| 1 | 0.0–1.8 | 朝のメイク前に\nベタつく美容液無理 | あさの めいくまえに、べたつく びようえき むり | `I`（1.8–4.0s）手の甲に1滴→伸ばす | 中央(`center`) | ドドン |
| ... | ... | ... | ... | ... | ... | ... |

- **締めの理由の重ね方**：①〇〇 → ②〇〇 → ③〇〇
- **ロジック1行**：（POV／持ち主／映像の手元・画との一致）

---

## 冒頭0〜3秒フック3案パック（精度向上オプション・推奨）
再生数の大半は冒頭 Cut 1（0〜2秒）で決まるため、本編（Cut 2以降）を1本に固めた状態で **Cut 1 だけ切り口を変えた3案（A：日常ストレス直撃／B：逆張り選別／C：視覚違和感）** を併記して比較選定します。
3案すべてを動画化して市場テストしたい場合は、`plan.json` の `hook_variants` に3案を渡すことで `render_video.py` が一括書き出しできます。
```
