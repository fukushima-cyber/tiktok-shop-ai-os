# Skill 04：TikTok口語台本 & 読み上げ・改行最適化

> **使うタイミング**：Skill 03のビートシートが確定した直後。
> **読むファイル**：共通ガイド（`00-os-principles.md`）＋ 案件ルール（NG語・特典の正式表記・読み指定）。
> **ゴール**：ぶつ切りやAI臭い意味不明文を防ぎ、「一本の自然な話し言葉」として通る日本語台本と、文節で綺麗に揃ったテロップ改行・TTS用ひらがな原稿を仕上げる。

---

## 1. 最重要：いきなり1カットずつの表で書かない（3ステップ執筆法）

いきなり表の1行ごとに15字の短文を埋めると、**主語・因果・話のつながりが壊れた「単語メモの羅列」** になります。必ず次の3ステップで書きます。

### Step 1：まず「連続した1本の話し言葉（130〜180字）」をベタ書きする
カット割りも改行も考えず、**カメラの向こうの友達に20秒でそのまま喋る1つの文章** として書きます。
- 冒頭（映像と100%一致する一言）→ 理由・体験 → 商品の答え → 見てわかる使用感 → 今買う理由の重ね方 → 左下誘導、が **1本の会話として自然につながる** 状態にします。

### Step 2：連続音読テスト（意味不明文・AI構文・成分朗読を潰す）
書いた1本の文章を最初から最後まで声に出して読み、次の **最悪パターン** が1つでもあれば書き直します。

| やりがちなダメ例（実測の失敗パターン） | なぜダメか | 直し方（✅ Good） |
|---|---|---|
| ❌「鏡じゃない、人に言われた」 | 鏡は喋らない。AI特有の無理な対比構文（「Aじゃない、Bだ」）で意味が壊れる。 | ✅「友達に『最近肌疲れてない？』って言われて地味にショックだった。」 |
| ❌「攻めるケア、足しすぎてた。見直したのは、成分。」 | ぶつ切りの体言止め連発で、なぜ見直したかの因果が飛んでいる。 | ✅「いろいろ重ね塗りしすぎてたから、一回シンプルなケアに戻したくて選んだのがこれ。」 |
| ❌「3つのCICAに、PDRN、ナイアシンアミド、ティーツリー、パンテノールまで、7つ。」 | ラベル成分のただの朗読。視聴者は「で、何が嬉しいの？」が分からない。 | ✅「CICAとか整肌成分が7種類入ってて、刺激が気になりにくい使い心地。」 |
| ❌「顔に使う前に、この質感で選んでる」 | 手持ち素材に顔がない言い訳を無理やり言葉にして、日本語の意味が破綻している。 | ✅「重たい美容液が苦手なんだけど、これは手の甲で伸ばした瞬間にすっとなじむ。」 |
| ❌「気になったら、左下から見てみて」（理由ゼロ） | 特典や今押す理由が何もなく、ただの宣伝終わりになる。 | ✅「今セールで普段より試しやすいから、ベタつく美容液が苦手な人は左下から見てみて。」 |
| ❌ 冒頭で「肌荒れ」と言っているのに、画はピカピカの手の甲 | 画と言葉が矛盾して0秒で違和感・離脱される。 | ✅ 画が「手の甲に1滴落とす」なら、言葉も「ベタつく美容液が無理な人、まずこの1滴見て」にする。 |

### Step 3：意味の切れ目でカット割りし、テロップの `\n`（改行位置）を明示指定する
連続文章が完成してから、1.5〜2.2秒（12〜20文字）のまとまりでカットに分けます。

#### テロップ改行の厳守ルール（下手な改行を構造的に防ぐ）
- **1行は最大10文字（半角英数は2文字＝1文字換算）、1カット最大2行まで**。
- **必ず台本側で `\n` を明示する**（自動折り返し任せにしない）。
- **単語・商品名・カタカナ語・数字＋助数詞を絶対に途中で割らない**。
  - ❌ `これはKINUIのカーム\nセブン` / `ナイアシンアミド、テ\nィーツリー` / `パンテノールまで、7\nつ`
  - ✅ `KINUIの\nカームセブン` / `手の甲に出すと\nとろっと1滴` / `気になったら\n左下から見てみて`
- **2行目に1〜2文字だけ落とす「孤立文字」は厳禁**（❌ `人に言わ\nれた` / `足しすぎ\nてた`）。
- **上下の行の文字数バランスを揃える**（例：7文字＋7文字、6文字＋8文字）。

## 1.5. 最重要ルール：機能押し禁止（必ず「生活ベネフィット」へ翻訳する）

**成分・容器・質感・スペックの説明だけで動画の半分以上を埋めてはいけません。**
機能説明は全体の **3割以内** に抑え、必ず **「だから、いつ・どんな生活場面がどう楽になる／どう気持ちよくなるか（ベネフィット）」** へ翻訳して書きます。

| ❌ 機能押し（スペック・使用感止まり） | ✅ 生活ベネフィット（行動・時間・気分の変化） |
|---|---|
| 「7つの整肌成分が入ってる」「CICAやPDRN配合」 | 「あれこれ重ね塗りしなくて済むから、**夜のスキンケアが1分で終わって迷わなくなる**」 |
| 「とろっとして伸ばすとツヤが出る」「なじみがいい」 | 「乾くのを待たなくていいから、**朝バタバタでもすぐファンデを塗れる**／**寝る前にすぐスマホを触れる**」 |
| 「スポイト式で量を調整しやすい」 | 「出しすぎてベタつく失敗がないから、**忙しい朝でも雑にサッと塗れる**」 |
| 「練り香水だから音がしない・缶が小さい」 | 「席やトイレで**誰にも気づかれずにサッと塗り直せて**、夕方まで香りを気にせず過ごせる」 |
| 「マグネット吸着で強力」（ガジェット） | 「カバンの中でコードが絡むイライラが消えて、**取り出して1秒で充電できる**」 |

> **テスト基準**：台本から「成分・容器・質感・数値（機能）」の文を全部消したとき、**使う人の具体的な生活場面（朝・夜・通勤・仕事・外出など）と感情・行動の変化が1つも残らない台本は不合格**。

## 2. 言語化とTTSの追加ルール

1. **禁止の抽象ワード**：`おすすめ` / `コスパ最強` / `画期的` / `すごい` / `最高` / `魅力的` / `必見` / `解決してくれる` だけで価値を語らず、見てわかる質感・場面・行動で書く。
2. **特典の正式表記は1文字も変えない**：案件ルールにある正式文言をそのまま貼る。終了日や価格は一次確認できるまで言わない。
3. **締めの「今買う理由」を2〜4段重ねる**（事実の範囲で）：お得・特典 → 使い道／失敗しにくさ → タイミング → 左下誘導。
4. **読み上げ（TTS）用ひらがな原稿**：
   - 行中の「。」は読み原稿だけ「、」に替える（0.3秒以上の無音間延び防止）。テロップはそのまま。
   - 商品名・成分名・数字・読み違えやすい漢字（`首元→くびもと`、`香り→かおり`、`1滴→いってき`）はひらがなで確定。
   - TTS（標準速）を書き出して `{全体の倍速}` をかけた実測尺が **25秒を超えたら、編集前に台本側で削る**。

```markdown
# 台本：【企画タイトル】

（ここにカット割り前の連続した全文を書く。声に出して意味・因果に1ミリも違和感がない状態にする）

---

## カット割り台本（\n で改行位置を明示・1行10文字以内・最大2行）
- **ターゲット**：
- **企画**：
- **型**：`Gxx` / `Pxx` × `Sxx`
- **訴求**：
- **未確認事項**：

| Cut | 目安秒(1.2x後) | テロップ（\nで改行明示・1行10字以内） | 読み（TTS用・ひらがな） | 絵（素材ID・画の内容） | テロップY位置 | 効果音 |
|---|---|---|---|---|---|---|
| 1 | 0.0–1.8 | ベタつく美容液が\n無理な人だけ見て | べたつく びようえきが むりな ひとだけ みて | `素材ID` 手の甲に1滴 | 下段(1240) | ドドン |
...

- **締めの理由の重ね方**：①〇〇 → ②〇〇 → ③〇〇
- **ロジック1行**：（POV／持ち主／使い道・関係／映像の手元・画との一致）
```
