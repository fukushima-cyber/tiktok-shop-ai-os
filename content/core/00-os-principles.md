# 00 定数OS：TikTok Shopアフィ運用の共通原理 & 標準プリセット

> どのアカウント・どの商材でも変わらない「定数」と、指定がないときに自動適用する「標準プリセット」を1枚に集約しています。
> これにより、人間が毎回細かい編集条件を入力しなくても、AIがそのまま高品質で動き出せます。

---

## 1. 共通の基本方針（全工程）

1. **事実と推測を分ける**：数字・実績・価格・終了日・成分効能は創作しない。未確認は「未確認」と書き、台本本文に「（対象のときだけ）」のような仮カッコ書きを残さない。
2. **機能押し・映像実況を禁止し、必ず「ベネフィット」を入れる（フォーマット別に最適化）**：成分・容器・質感・開封手順はあくまで画面で見せる証拠であり、買う理由そのものではない。画面を見れば分かる動作（「開けてみる」「キャップを外す」「1滴落とす」「伸ばす」）をそのまま言葉で実況せず、**画＝視覚の証拠、言葉＝買い手の本音とベネフィット** に役割分担する。**通常尺（20秒〜）は生活ベネフィット2場面以上、超短尺速報（10〜15秒）や無言シズル先行型は核心ベネフィット最低1点** を必ず入れる（ベネフィット0の動画は全フォーマット禁止）。複数案を作るときは特徴の言い換えにとどめず、**動画のフォーマット（尺・語り手の立ち位置・演出構造）自体を別物に分ける**。
3. **減点ルールだけで企画しない**：NGを避けるだけでは伸びない。まず「伸びる原理8つ（加点）」と「生活ベネフィット」で設計し、最後に独立レビューでNG・矛盾を削る。
4. **B-roll × 自社素材のハイブリッドで画に変化をつける（ベース映像のAI生成は完全禁止／編集エフェクト・GIFはOK）**：自社撮影素材（商品・手元）だけで全カットを埋めると同じ背景が続いて飽きられやすい。**前半の悩み・日常・共感パートには、共有Driveの共通素材・公開RED・Mixkit / Pexels の実写生活 B-roll（顔なし・手元/物/空間カット優先）を積極的に混ぜ、後半の答え出し・塗布・ラベル・CTAを自社素材で締める**。また、箱→開封→キャップ→塗布の撮影順どおりに並べる必要はない（0.0秒には動き・質感・変化が最も強いカットを先出しする）。**ベース映像のAI動画生成・AI画像生成（静止画スライド含む）・仮画面での代用は完全禁止**。実写映像の上に乗せる編集エフェクトやオーバーレイ（左下白矢印GIF・コメント吹き出しPNG・要点バッジ等）の作成は許可する。手元の雰囲気（性別・ネイル・背景）と話の主語を必ず一致させる。
5. **3つの確認ゲートを守る（人間の手間は「記号選択／OK」だけ）**：
   - **ゲートA**：企画候補（2〜3案）の選定
   - **ゲートB**：独立レビュー通過後の台本・ビートシート承認
   - **ゲートC**：完成動画2本（効果音あり／ナレのみ）＋コンタクトシート＋検査ログの確認
6. **無断実行の禁止**：投稿・広告出稿・コメント送信・有料素材の購入は依頼者の明示承認なしに行わない。
7. **未決項目の扱い（無言停止しない）**：アカウント設定が未指定なら下の「標準プリセット」を自動適用する。商材ファクト（特典の有効性など）に未確認がある場合は「未確認」と明記したうえで進行し、投稿前の確認欄にまとめる。

## 2. 伸びる原理8つ（実測ベース・企画と台本の加点基準）

公開TikTok調査（カームセブン266本・美容154本・センスウェア67本・DPro EC841件）から抽出した共通原理です。企画と台本は必ずこの原理を組み込みます。

| # | 原理 | 実測の根拠 | 制作での具体ルール |
|---|---|---|---|
| **1** | **冒頭は「他人の目が絡む痛い一言」か「強い違和感」で止める** | 対人ショック型の中央値が最多（45,098再生）。「言われたい（願望）」より「言われた（事件）」が強い。 | 挨拶・自己紹介・レビュー宣言は禁止。0〜1.5秒に「誰×場面×事件/違和感」を置く。 |
| **2** | **感情は「マイナス→転機→変化」の一方向に動かす** | 「悔しい→見返す」「失敗しそう→裏返しで納得」が1本の中で完結する動画は完走されやすい。 | 話題を散らさない。1動画＝1つの悩み/誤解→1つの解決に絞る。 |
| **3** | **商品は「答え」として後から出す（手元・箱は背景で先出し可）** | 「何の話か」が先、「何の商品か」が後の方が広告臭が消え完走される。 | 冒頭から商品名を連呼しない。ただし手元や箱を背景に映して視覚で匂わせるのは有効。 |
| **4** | **信頼は言葉ではなく「目で見える事実」で作る** | Before/After・質感・塗布動作（とろみ・伸び・ツヤ・すくう動き）の視覚証明が強い。 | 「すごい」「効く」などの抽象語を禁止し、画面に見える事実と使用感の情景で語る。 |
| **5** | **テンポは「1.5〜2.0秒で切る、間延びゼロ」** | 上位30本の中央値は平均カット長1.64秒・最初のカット切れ1.64秒。 | **1カット＝1テロップ＝1.5〜2.0秒**。全体の尺は型と内容に合わせて設計し、無音余白・静止画・間延びワードを入れない。 |
| **6** | **CTAは1つ。場所を指すだけ** | 上位30本のCTAはほぼ「左下ショップ」の1文のみ。派手な赤矢印・白フラッシュは広告臭で逆効果。 | 最後は「どこを押せばよいか」をシンプルに1つだけ示す。 |
| **7** | **通常期はセールを締めに重ね、公式セール期（トクトクSALE・ブラックフライデー等）は他商材の勝ち型から輸入して使う** | 通常期はセール冒頭型が低反応だが、トクトクSALE実測11本（2026-11-25調査：最大739万再生・42,561いいね、23〜75秒）では食品・家電・日用品で「買い時・割引・期限・後悔逆転・リピート」を前面に出す動画が爆伸び。美容系でトクトクSALE勝ち例はまだ空いているため、家電・食品・日用品の勝ち型を美容へ輸入する余地が大きい。 | **通常期**：商品提示後に理由を2〜4段重ねる。<br>**トクトクSALE／ブラックフライデー期**：実測勝ち型（①「やっっと買い時きた」まとめ買い型 ②「買って後悔した→もっと早く買えばよかった」逆転本音型 ③ブラックフライデー／価格確認の速報フラッシュ型 ④「また買い足した」リピート・消耗品確保型 ⑤権威・意外性フック型）からフォーマット自体を変えて設計する。※具体割引率・終了日は公式アンカー一次確認時のみ記載し、未確認時は「今いくらだと思う？／セール対象」で左下確認を促す。 |
| **8** | **画に映る人と、話の主語をそろえる** | デコネイルの手で「男磨き」と語る、隣の男性の話なのに女性素材だけ並べる等のズレが離脱と差し戻しの主因。 | 動画に映る手・服・部屋・小物の持ち主と、語り手の設定を100%一致させる。 |

## 3. TikTok Shopアフィ用の「3段階評価軸」（PDCA基準）

「有機いいね率0.5%」単一基準だけだと、**いいねは少ないが注文（CV）が取れる商品直球型や比較型を誤って切る** ため、以下の3段階でボトルネックを切り分けます。

| 層 | 主指標（48時間時点・有機優先） | 合格目安 | 未達時の原因箇所と次の一手 |
|---|---|---|---|
| **第1層：止める（フック）** | 有機再生数 / 2秒維持率 | 再生 **1,000以上** | **冒頭0〜3秒だけ変更**（中盤・商品パートは固定） |
| **第2層：観る・残す（構成）** | いいね率（いいね÷再生）または 保存率（保存÷再生） | いいね率 **0.5%以上** または 保存率 **0.15%以上** | **中盤の構成・絵のテンポ・語り口を変更**（冒頭は固定） |
| **第3層：買う（商品・オファー）** | カートクリック率 / 注文数（CV） | 注文発生 または 高保存＋クリック反応 | **商品パートの情景化・理由の重ね方・CTAを変更** |

- **全層未達（再生1,000未満 かつ いいね率0.5%未満 かつ 保存率0.15%未満 かつ 注文0）**：その型（企画型×台本型）は撤退し、型ごと変える。
- **広告配信（Spark Ads等）の数字と有機の数字は必ず分けて記録する**。広告の再生数を「有機で伸びた」と誤認しない。

## 4. 新規制作 vs PDCA検証の分岐ルール

| 依頼の種類 | 型の選び方 | 変えてよい範囲 |
|---|---|---|
| **新規の1本**（または指定なし） | 直近投稿した型・確認待ちの型・撤退済みの型を**避け、新しい型（企画型×台本型）**を選ぶ。 | 型ごと変える（変えた項目は「型」と記録）。 |
| **前作の検証（PDCA）** | 前作と**同じ型**を維持する。 | 48時間判定に従い **1変数だけ** 変える（冒頭だけ／中盤だけ／商品パートだけ）。 |

## 5. 全商材共通のコンプライアンス（薬機法・景表法・ステマ規制）

- **治療・機能変化の断定禁止**：「治る」「治す」「消える」「若返る」「シワがなくなる」「毛が生える」「やせる」「体臭が消える」「ニキビが治る」は台詞・テロップ・キャプションすべてで禁止。
- **絶対表現の禁止**：「絶対」「必ず」「100%」「誰でも」「一晩で」「最強」「No.1（一次根拠なし）」は禁止。体験は個人の使用感の範囲にとどめる。
- **医療・専門家の誤認禁止**：白衣着用や「皮膚科医も推奨」等の事実確認できない権威演出は禁止。
- **ビフォーアフターの誠実性**：同一部位・同一光量・無加工。メイク効果や個人差の注記が必要な商材は画面に明記する。
- **特典・価格・No.1表記**：今有効と確認できた正式表記のみ使用。終了日・割引率・累計販売数は一次情報で確認できない限り書かない。「無料」単独表記は避ける。
- **PR・ステマ表記**：キャプションおよび動画内の規定位置に `#PR`（またはTikTok Shopのコミッション表示）を必ず入れる。

## 6. 尺と出力仕様の定数

- **完成尺（倍速処理後）**：**固定の上限は設けない**（目安15〜45秒前後）。型や訴求内容（生活ベネフィット・比較・ストーリー等）が自然に伝わる長さにし、短く収めるためにベネフィットや根拠を削らない。代わりに1カット1.5〜2.0秒のテンポと無音ゼロを徹底する。
- **解像度・フレームレート**：縦9:16（`1080×1920` / `30fps`）、全カット画面いっぱい（ぼかし帯・枠なし）。
- **色と反転**：色加工（彩度・LUT・ノイズ処理）と左右反転は禁止。HDR（HLG）素材とSDR素材を混ぜる場合は、`06-editing.md` の指定式で色空間変換のみ行う。
- **納品物**：効果音入りの本線mp4＋効果音なし（ナレのみ）mp4の2本＋コンタクトシート＋検査notes。

## 7. 標準アカウント・編集プリセット（指定がないときに自動適用）

依頼者から個別のアカウント設定（変数A）が渡されない場合、AIは質問で止まらず、以下の検証済みデフォルト値を自動適用して進めます（依頼者が一部だけ上書きすることも可能です）。

| 項目 | 標準プリセット値 |
|---|---|
| **話し手・口調** | 特定の職業は名乗らず、顔なし・声＋テロップで進行。友達に本音を話すフラットなタメ口寄り口語（一人称は原則省略） |
| **顔出し可否** | **一切不可**（ぼかし・モザイクも不可） |
| **使える素材** | 自社素材（商品アップ必須）＋ RED素材（2倍以内寄せで透かし・顔・中国語を除去できるもの）＋ フリー素材（RED不足時のみ） |
| **生成素材（ベース映像のAI生成／編集エフェクト）** | **ベース映像のAI動画/画像生成・仮画面は完全禁止**（実写の自社・RED・フリー素材のみ。足りなければ止まって依頼する）。実写の上に乗せる **編集用エフェクト・GIFオーバーレイ（白矢印・吹き出し等）の作成はOK**（赤矢印連打・白フラッシュ・色加工はNG） |
| **ナレの声** | Microsoft 日本語音声「Nanami」（`ja-JP-NanamiNeural` / `edge-tts`）。標準速1.0xで生成 |
| **全体の倍速** | **1.2倍（+20%）**。映像と音声をまとめて最後に1.2倍（二重倍速禁止） |
| **音量目標** | **-14 LUFS**（ピーク `-1dBFS` 以下、割れサンプル 0） |
| **テロップの見た目・配置** | 白太字（`Noto Sans CJK Bold` / `ヒラギノ角ゴシック W8`）＋黒縁取り＋影、**画面ど真ん中（上下左右中央：`y=center`）固定**。**句読点（、。）は入れず**、句読点を打つ自然な区切り位置で `\n` 改行する（1行10文字以内・最大2行・収まりに字を小さくしない） |
| **締めの誘導（矢印）** | TikTok Shop左下商品リンク（`y=1430〜1530`付近のカートボタン）の**すぐ上（安全領域内 `x=80〜380, y=1130〜1410`）から左下商品リンクを正確に指す白い矢印のみ**（UIの下に潜る位置・赤い矢印・白フラッシュ禁止） |
| **PR表記** | キャプション末尾に `#PR`（TikTok Shopコミッション表示と併用） |
